# Personal Budget Tracker

## Project Description

My Budget Tracker is a simple web page created using HTML and CSS. It allows users to view sample expenses and enter information for a new expense.

## 1. Expense Table

The project contains an expense table with four columns:

* Name
* Amount
* Category
* Date

The table uses HTML elements including `table`, `thead`, `tbody`, `tr`, `th`, and `td`.

Five sample expenses have been included.

The table is styled with borders, cell padding, a colored header, alternating row colors, and a hover effect.

## 2. Add Expense Form

The Add Expense section contains a proper HTML form where users can enter:

* Expense name
* Amount
* Category
* Date

The category field is a dropdown containing five options:

* Food
* Transport
* Rent
* Entertainment
* Other

The form also contains an "Add Expense" button.

The button does not have JavaScript functionality yet because JavaScript functionality will be added in a future week.

## 3. Multimedia Content

A budget tracker logo has been added using an `img` element with `src`, `alt`, and `width` attributes.

A budgeting video has also been embedded using an `iframe` with width, height, title, and frameborder attributes.

## 4. Interactive Elements

A collapsible "How to use this tracker" section was created using `details` and `summary`.

The table rows change their background color when the mouse moves over them.

The Add Expense button uses `cursor: pointer`.

Input fields also have a focus effect when the user clicks on them.

## 5. Advanced CSS Selectors

The project uses several advanced CSS selectors:

* Descendant selector
* Direct child selector
* `:nth-child()` pseudo-class
* `:not()` negation pseudo-class
* `:focus` pseudo-class
* `:hover` pseudo-class
