# Personal Budget Tracker

## Project Description

My Budget Tracker is a simple web page created using HTML and CSS. It allows users to view sample expenses and enter information for a new expense.

## 1. Expense Table

The project contains an expense table with four columns:

* Name
* Amount
* Category
* Date

The table uses HTML table elements including `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`.

Five sample expenses have been included.

## 2. Add Expense Form

The Add Expense section contains a form where users can enter:

* Expense name
* Amount
* Category
* Date

The category field is a dropdown with five options:

* Food
* Transport
* Rent
* Entertainment
* Other

An "Add Expense" button is also included. The button does not have JavaScript functionality yet.

## 3. Multimedia Content

A budget tracker logo has been added using an `<img>` element with an `src`, `alt`, and `width` attribute.

A budgeting video has also been embedded using an `<iframe>`.

## 4. Interactive Elements

A collapsible "How to use this tracker" section was created using `<details>` and `<summary>`.

The expense table rows have a hover effect, and the Add Expense button uses `cursor: pointer`.

## 5. Advanced CSS Selectors

The project uses several advanced CSS selectors:

* Descendant selector
* Direct child selector
* `:nth-child()` pseudo-class
* `:not()` pseudo-class
* `:focus` pseudo-class
* `:hover` pseudo-class

## Technologies Used

* HTML5
